# Ядро интернет-магазина

Реализованы классы `Product` и `Category` с поддержкой:
- Приватных атрибутов и валидации данных
- Автоматического подсчёта количества товаров и категорий
- Строкового представления объектов (`__str__`)
- Сложения товаров для расчёта общей стоимости (`__add__`)
- Наследования и типобезопасных операций

## Функционал

- **Класс `Product`**: название, описание, цена (с защитой от ≤0), количество.
- **Класс `Category`**: название, описание, список товаров, счётчики категорий и товаров.
- **Тесты**: покрытие >75%, проверка всех ключевых сценариев.

### Базовые классы
- **Класс `Product`**: название, описание, цена (с защитой от ≤0), количество.
- **Класс `Category`**: название, описание, список товаров, счётчики категорий и товаров.

### Классы-наследники
- **`Smartphone`** (наследник `Product`):
  - производительность
  - модель
  - объём встроенной памяти
  - цвет

- **`LawnGrass`** (наследник `Product`):
  - страна-производитель
  - срок прорастания
  - цвет

### Защита типов
- Сложение товаров разрешено только внутри одного класса (используется `type()`)
- Метод `add_product` принимает только объекты `Product` и его наследников (используется `isinstance()`)

## Запуск

Проверочный код из задания:
```bash
python main.py
```

## Тестирование
Запуск всех тестов:
```bash
poetry run pytest tests/
```
Проверка покрытия:
```bash
poetry run pytest --cov=src --cov-report=term tests/
```

## Технологии
- Python 3.12
- Poetry (управление зависимостями)
- Инструменты качества: black, isort, flake8, mypy, pytest
