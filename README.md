Ядро интернет-магазина: реализованы классы `Product` и `Category` с подсчётом количества товаров и категорий.

Функционал:
- Класс `Product`: название, описание, цена, количество.
- Класс `Category`: название, описание, список товаров, автоматический подсчёт категорий и товаров.
- Тесты с покрытием >75%.
